# worm-fluorescence

**线虫荧光处理技能：AI辅助逐虫圈选，ImageJ测量，同步保留可编辑ROI与训练候选标注。**

公开试用版：v0.3.0-beta.1。面向愿意检查轮廓的研究者；目前验证Windows、单帧8位RGB图像。无需worm_deep、YOLO模型或PyTorch。

## 工作方式

研究者提供图片和纳入规则 → 能看图的AI代理逐虫描边、遇疑询问 → 本地ImageJ读取原图测量 → 输出逐虫数据、ROI、复核页和训练候选。

单独运行Python脚本不会自动识别新虫。视觉判断依赖所用AI模型及人工复核；项目没有提供独立验证的识别准确率。开源的是技能与脚本，不包含AI模型或使用额度。

## 可以得到什么

- 逐虫原生ImageJ结果：Area、Mean、Min、Max，并另保留Area_px。
- 可在ImageJ中编辑的ROI和ROI集合。
- 可切换轮廓的逐图/局部复核页、提示性质控和原图校验记录。
- YOLO轮廓、Labelme和逐虫独立掩膜；交叉虫可按约定共享像素。
- 增量缓存：只重算变化项，保留历史结果。

当前Mean是**RGB三通道非加权亮度**，不是绿色通道均值；不扣背景。灰度、16位、多通道、堆栈、其他测量口径尚未支持，不静默转换。图像导出DPI也不是显微镜空间标定。

## 开始试用

先按[安装与首次验证](INSTALL.md)配置Python、ImageJ/Java和本机路径。在能读取本地图片并执行Python的Codex环境安装完整技能目录；当前官方说明见[Codex技能文档](https://developers.openai.com/codex/skills/)。然后可以说：

> 使用 $worm-fluorescence 处理这个文件夹。先选3张代表图，确认测量和纳入规则，给我荧光表、ROI和复核页。

首次试用先运行合成验证，再用自己1—3张真实图，在本机ImageJ复测相同ROI。不要首次就批量处理全部实验。

## 配置与验收

每批analysis_rules.json记录实际确认的测量、边缘虫、交叉虫和小虫规则；默认未确认。[规则格式](references/analysis_rules.md)支持记录不同研究者的选择，脚本不会自动判断完整比例或发育异常。

数值复算、边界认可、训练覆盖分别记录。未标虫段不能当背景；只有边界认可且覆盖完整的样本进入训练可用清单。默认仅积累候选，训练需另选工具并单独启动。

## 验证范围

提供[可重复检查](docs/VALIDATION.md)：实际ImageJ合成测量、原像素复算、重合掩膜、触边、规则确认、缓存、修改后验收失效、16位拒绝、裁剪与同源划分检查。合成矩形不是实验数据，也不是识别精度测试。

本次发布的验证结果和限制见[验证记录](docs/VALIDATION.md)。仍需其他电脑、操作者与更多真实图片检验；更换AI模型后不应假定边界效果相同。
