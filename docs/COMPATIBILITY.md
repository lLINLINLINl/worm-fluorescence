# 1.x兼容约定与版本更新

1.0.0把已经验证的工作流作为首个正式兼容基线。支持范围为Windows、推荐Python3.13、单帧8位RGB图像，以及由能看图的代理描边并经使用者复核的ImageJ定量；正式版本号不代表无缺陷、自动分割模型或独立真实线虫识别准确率认证。

## 对外稳定的约定

- 文档中已公布的workflow命令、必填参数和现有参数含义在1.x内保持兼容。增加可选参数可以扩展功能，但旧命令应继续工作。
- 文档化的selections.json轮廓输入、schema_version=1的批次规则和逐虫统计资格结构保持可读；旧版可选字段可以继续缺省。boundary_key、rules_key等校验指纹是不透明状态标记，不承诺其具体字符串跨升级不变；失效后须依据实际证据重新核定。
- 默认测量口径保持RGB三通道非加权原始亮度、不扣背景。Mean不是绿色通道均值；Area_px是像素面积，文件DPI不是显微空间标定。新增通道或背景算法需由用户显式选择，不能静默替换默认口径。
- included_precise.csv及同内容本机别名保持下列字段名称、顺序和含义，保留原始数值精度：

```text
Group,ImageID,SourceFile,WormID,Mean,Min,Max,Area_px,Area_ImageJ,AreaUnit,BackgroundSubtracted,Method,InclusionNote,BoundaryVerified
```

- 原生ImageJ表、可编辑ROI、仅纳入区域的最终强度表和无强度值排除清单维持文档说明的用途。export的全部技术测量行不自动等同于finalize筛选后的统计行。
- 原始图片只读；统计资格与边界认可分别记录。待定或过期资格仍阻止最终统计，不把端点认可扩大为整图认可。

HTML布局、派生显示图的样式、内部Python函数、内部暂存/缓存/历史文件的组织不是稳定调用接口；变化可以使派生图或缓存重建，但必须保留源图与可追溯性。AI模型或实际轮廓不同可能导致测量范围变化，不能把相同版本号当作相同轮廓的保证。

## 什么时候升级哪个数字

| 类型 | 版本示例 | 本项目的判断 |
| --- | --- | --- |
| 兼容的问题修正 | 1.0.0 → 1.0.1 | 修复路径、导出或实现错误，旧命令与公开格式仍可用 |
| 兼容的功能新增 | 1.0.1 → 1.1.0 | 新增可选导出、可选测量模式或可选识别器，保留旧默认流程与口径 |
| 不兼容的公开变更 | 1.4.2 → 2.0.0 | 删除/改变原命令或必填参数、改变既有CSV字段/顺序/含义、默认测量改为绿色通道或扣背景、旧配置必须手工改写、提高已承诺支持的最低运行环境 |

主版本更新取决于使用者是否必须修改既有调用、数据读取或结果解释。代码重写很多、更新次数多、增加了模型、速度提升或修复严重缺陷，本身都不能直接决定要升2.0；仍需判断是否破坏公开约定。存在不兼容变更时，即使只改一行也应升级主版本；主版本递增后，次版本和修订号归零。

修复错误算法可能使受影响结果改变；若修复恢复的是原本承诺的正确行为，可以使用修订号，但必须在更新记录说明受影响版本、结果影响及是否需要重测。若有意改变既有测量定义或默认算法，则属于不兼容变更。新增列请优先另设输出格式/文件，避免悄悄改变固定全精度CSV。

弃用是告知未来将移除，不能立即破坏现有调用：可以在1.x次版本中增加弃用提示，在2.0移除，并提供迁移说明。已发布版本和标签不覆盖；发现问题发布新版本。新主版本可先发布2.0.0-beta.1或2.0.0-rc.1供迁移验证。

规则依据：[语义化版本2.0.0规范](https://semver.org/lang/zh-CN/)。本文件是本项目对公开接口与格式的具体约定；功能支持与验证限制仍以README、INSTALL和验证记录为准。
