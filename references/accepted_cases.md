# 边界复核参考

仓库不包含私人实验图、结果或个人路径。常见复核类型包括：

| 失败类型 | 校准重点 |
| --- | --- |
| 右半部下缘或上侧暗边漏圈 | 关闭红线，再沿亮核心对面的身体连续边缘检查；仅提高亮度仍可能漏边 |
| 细尾与外部纤维、团块相连 | 展示完整图与A/B局部；每图独立确认，不把某图的A或B当作通用截止规则 |
| 可辨但过短的虫段混入统计 | 对照本批明确排除实例，保留轮廓并单独排除强度 |
| 较短正常虫被误排 | 同时准备已认可纳入的正例，不能只看绝对长度 |
| 多虫相交、回弯似分叉 | 每虫固定编号、标端点和连接方向，允许共享像素时独立ROI |
| 游离亮点、气泡弧线和绿色背景 | 围绕实际虫体形态检查，不把亮团或细圆弧直接当虫体 |

本机可在`references/local_accepted_cases.md`记录真实图位置、修订版本、用户原话及认可范围。该文件和真实图片不进入Git/分享包。用于校准的案例不是独立测试集，不能用于宣称识别准确率。

仅根据当前图判定，个体决定不跨图套用。真实案例由使用者提供获准使用的图片，并分别记录边界验收。合成示例只验证软件，不证明真实线虫识别能力。
