# 整个虫体外缘的检查

用于暗侧漏圈、细尾、交叉和相连团块；不是自动分割算法。

1. **先看无圈线原图。** 在足够分辨率下确定虫数、头尾、转弯和出画位置，再看增强图。增强可能使颗粒团和纤维变得显眼，亮度本身不能证明身份。
2. **沿两侧各走一遍。** 从一端沿一侧到另一端，再沿对侧回查，重点看弯曲内外缘、右下等暗侧及突然变窄处。不能只沿亮核心描点；暗边应有与身体连续的形态证据。
3. **关闭轮廓检查线下。** 红线宽度可能遮住微弱细尾或暗边。并排查看原始亮度无圈线、统一增强无圈线、薄线叠加图；增强仅显示用，ROI始终回到原图坐标。
4. **交叉分别追踪。** 给每条虫固定编号，标出各端和连接方向；允许共享像素时独立圈选。问“W01的这端接左下还是右上、总共几条虫”，不要只问含糊的“交叉归属”。
5. **细尾和相连团块逐处判定。** 身体连续性、宽度变化及形态共同判断。无法区分虫体/纤维/团块时展示A/B端点或D结构；不凭越亮越好、越细越该排除等假设延长或截断。
6. **最后回看完整图。** 检查所有可辨虫体是否记录、编号是否稳定，以及统计排除的轮廓是否仍保留。统计排除与训练标注覆盖是两件事。

有歧义时先生成图，不必先测量：

```powershell
python $wf question --run $runDir --images C_009 --worms W03 --note 'W03上侧暗边是否已圈全？'
# 指定更小的尾端局部；坐标为原图像素，右/下不含
python $wf question --run $runDir --images C_018 --box 300 100 650 300 --markers '端点标记.json' --note 'W02右端到A还是B？'
```

标记JSON为列表，例如`[{"image_id":"C_018","x":500,"y":180,"label":"A"}]`，坐标必须来自当前图，不套用示例。`review/questions/展示给用户.md`含绝对路径图片语法：在对话中直接嵌入完整图和对应局部，同时保留无圈线原始/增强图供查看。图名包含内容指纹；轮廓、局部框、标记或文字改变后会生成新版本，旧图保留。question不记录认可，不改ROI或测量。
